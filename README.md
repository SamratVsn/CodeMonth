# CodeMonth

**30 Days of Coding** — an Android app created as part of my learning journey to help myself and others follow a structured coding practice path.

This project is a mobile application built in **Kotlin** using **Jetpack/Android tools**, designed to present a **30-day plan for learning programming and coding fundamentals**.
