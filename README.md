# CodeMonth

**30 Days of Coding** — an Android app built as part of my learning journey, designed to present a structured 30-day path for learning programming and coding fundamentals.

## About

Named "30 Days of Coding," this app outlines a day-by-day roadmap for learning core programming concepts. It was built to help maintain a consistent learning routine and track progress through a 30-day pathway — both for myself and anyone else following along.

## Features

- Daily breakdown of coding topics/tasks
- Simple interface to navigate through each day
- Encourages incremental, consistent learning

## Tech Stack

| Technology | Purpose |
|---|---|
| Kotlin | Primary programming language |
| Android SDK | Mobile app platform |
| Jetpack Components | Architecture and UI building |
| Gradle | Build system |

## Getting Started

To build and run this project locally, you'll need:

- Android Studio (recent stable release)
- Android SDK and build tools installed
- A device or emulator for testing

### Clone the Repository

```bash
git clone https://github.com/SamratVsn/CodeMonth.git
cd CodeMonth
```

Open the project in Android Studio, let Gradle sync, then run on an emulator or physical device.
